## 💛 自用版简介

买早餐、打车、逛超市，或是收到一笔报销，都可以顺口记下来。少一点逐条填写，多一点日常坚持。✨

## 🧾 主要功能

除了本次调整，也保留了原项目的常用记账功能：

- **✍️ 手动记账**：记录收入和支出，填写分类、金额及备注。
- **🎙️ 语音多笔记账**：一段话包含多笔收支，识别后自动拆分、逐笔保存。
- **📈 收支统计**：通过月、年日历和分类排行，了解钱花在哪里。
- **📚 多账本与多账户**：按不同用途管理账本和账户，支持账户间转账。
- **🏷️ 预算、标签与周期账单**：设置预算、整理记录，管理固定收支。
- **📥 账单导入导出**：导入已有账单，也可导出记录留作备份。

## 🚀 怎么使用

**配置好 AI 服务的 Key 后，就可以直接使用语音记账。** 手动记账无需配置 AI。

1. **🔑 首次配置**：在服务商管理中填写自己的 Key，具体位置见下方“AI 配置”。
2. **🎙️ 点击语音**：打开首页，点击底部“记账”右侧的“语音”按钮，首次使用允许麦克风权限。
3. **🗣️ 说出账单**：一次可以连续说多笔，说完点击“完成”，系统会识别内容并自动拆分保存。
4. **✅ 查看结果**：保存后到“明细”查看和修改，再通过“洞察”中的月、年日历了解收支。

### 💬 一句话，记下多笔收支

> “早餐12元、打车28元、买菜56元、收到报销200元。”

这段话可以拆分为：

| 内容 | 类型 | 金额 |
|---|:---:|---:|
| 🍳 早餐 | 支出 | ¥12.00 |
| 🚕 打车 | 支出 | ¥28.00 |
| 🥬 买菜 | 支出 | ¥56.00 |
| 💰 收到报销 | 收入 | ¥200.00 |

**一次说完，无需逐条填写。** 也可以使用日常表达，例如“今天买了鞋带，花了12块七毛五”。

> 💡 当前单次录音最长 **29 秒**。识别成功的账单会直接保存，请在明细中核对；如果提示部分失败，先查看已保存的记录，再补记遗漏内容。

## 🔑 AI 配置

进入 **我的 → 智能记账 → AI小助手 → 服务商管理**，分别填写自己的服务商 Key。

| 默认服务 | 负责什么 | 当前预设 |
|---|---|---|
| **DeepSeek** | 理解文字内容、提取多笔收支信息 | `deepseek-flash` |
| **智谱 GLM** | 将录音转成文字 | `glm-asr-2512` |

按默认配置使用语音记账，需要同时配置 **DeepSeek 和智谱的 Key**。服务商地址和模型名称已有预设，填写有效 Key、确认对应能力绑定后即可使用。

🔐 **本自用版源码与新安装包不内置 API Key**，需要在 App 内自行填写。

## 📂 数据在哪里

- **账本在设备上**：App 在手机运行，账本就保存在手机的应用私有目录；在模拟器运行，则保存在模拟器内部。
- **AI 识别需要联网**：语音和文本会发送给配置的识别服务，账本本地存储不代表 AI 识别离线运行。
- **日常可以导出备份**：通过账单导出功能保存副本，方便留存和迁移。
